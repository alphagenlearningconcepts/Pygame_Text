Core Decisions

Let's Understand Text in Pygame

Displaying text in Pygame requires 3 major decisions and syntax steps:

Step 1

Create Font

Picks the font style and size for rendering words.

# Syntax:
font = pygame.font.Font(None, 36)
Step 2

Render Text

Converts string text into a drawable Pygame Surface object!

# Syntax:
text = font.render(msg, True, color)
Step 3

Blit (Stamp) to Screen

Stamps the rendered text surface onto coordinates (X, Y).

# Syntax:
screen.blit(text, (x, y))

Font Selection Options

Pygame Fonts: Default, System & Custom .TTF

Pygame gives you 3 primary ways to choose your font style:

Option 1

Default Font (None)

Pass None as the font file to use Pygame's built-in default font!

font = pygame.font.Font(None, 36)
Option 2

System Fonts (SysFont)

Use installed system fonts like "arial", "courier", or "timesnewroman"!

font = pygame.font.SysFont("arial", 36)
Option 3

Custom .TTF File

Download custom .ttf font files and load them directly into your project directory!

font = pygame.font.Font("arcade.ttf", 36)
✨ Pro Tip: You can download free retro arcade fonts in .ttf format from Google Fonts or DaFont and place them in your project folder!
Loop Architecture

Inside vs. Outside the Game Loop

OUTSIDE WHILE LOOP

One-Time Initialization

Executed only ONCE when the app starts. Used to setup font objects and initial variables!

score = 0
font = pygame.font.Font(None, 36)
INSIDE WHILE LOOP

Per-Frame Dynamic Rendering

Executed 60 times per second! Required whenever text variables (like score) change.

while running:
text = font.render(f"Score: {score}", True, col)
screen.blit(text, (50, 50))
⚠️ If rendering score is placed outside loop, the text never updates when score increases!

Teacher & Student Discussion

Key Observations

Share your thoughts with your teacher first, then click each card to check the answer!

1. Where should I put dynamic text like Score?

Inside the While Loop! Dynamic variables like score change every frame, so font.render() must run inside the game loop to display updated values!

2. Which value changes text color?

The 3rd argument in font.render()! Pass an RGB tuple like (255, 208, 113) for yellow or (255, 0, 0) for red.

3. How do I position text at the top of screen?

Change coordinates in screen.blit()! Setting Y to a small value like (100, 10) keeps text pinned near the top banner!

4. What if I don't like any default font?

Download a .TTF font file! Save the file inside your project directory and load it with font = pygame.font.Font("custom.ttf", 36)!
